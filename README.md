### 🐹 Golang Projects

| [EventBooker](https://github.com/iapparov/EventBooker) | Сервис бронирования мероприятий (концерты, курсы, лекции) с автоматическим контролем дедлайнов. Если бронь не подтверждена вовремя — место освобождается автоматически; уведомления отправляются через Email или Telegram | Go, PostgreSQL, RabbitMQ, JWT, SMTP, Telegram Bot API, Docker |
